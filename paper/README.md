본문 그림 2는 CGR의 양쪽 패드가 두 비교 방법보다 뚜렷하게 레몬 표면에 가까웠던 사례다. 한 장면을 고른 기준과 전체 후보의 집계값을 함께 제시했다. 접촉 항만 제거한 비교와 물체를 들어 올려 유지하는 실험은 후속 검증으로 구분했다.
