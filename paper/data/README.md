# 표 1의 프레임별 측정값

[frame-metrics.csv](frame-metrics.csv)는 같은 HRDexDB 레몬 시연에서 계산한 파생 지표다. 각 행은 원본 프레임 하나와 공통 Franka Panda에 적용한 방법 하나를 나타낸다. 짝수 프레임 0∼230 중 사람의 엄지와 검지에 모두 접촉 후보가 있고 레몬이 보이는 62개를 사용했다. 세 방법에 대해 총 186행이며 모든 행에서 공통 역기구학 해가 유효했다. 서로 이웃한 프레임을 포함하므로 독립된 파지 시도 수는 한 편의 시연과 구별해야 한다.

| 열 | 정의 |
| --- | --- |
| `frame`, `method`, `ik_valid` | 0부터 세는 30 Hz 원본 프레임, 방법 이름, 공통 Panda 역기구학의 유효성 |
| `left_pad_q05_surface_mm`, `right_pad_q05_surface_mm` | 각 고무 패드 안쪽에서 면적에 따라 뽑은 512개 점과 레몬 삼각형 메시 사이 부호 없는 최단거리의 5백분위수(mm) |
| `max_pad_q05_mm` | 좌우 패드의 5백분위수 중 큰 값(mm). 표 1 마지막 열은 이 열의 방법별 중앙값 |
| `left_pad_area_within_3mm`, `right_pad_area_within_3mm` | 각 패드의 표본 중 레몬 메시에서 3 mm 이내인 비율(0∼1) |
| `left_pad_visible_px`, `right_pad_visible_px` | 원본 카메라 시점에서 깊이 검사 후 남은 각 로봇 패드의 렌더 픽셀 수 |
| `lemon_visible_fraction` | 투영된 레몬 실루엣 중 로봇에 가려지지 않고 보이는 비율(0∼1) |

## 그림 선정을 다시 계산하는 법

- **그림 2 (184번)** — 각 프레임에서 같은 쪽 패드끼리 비교해 ‘비교 방법 거리 − CGR 거리’를 계산한다. 두 패드와 두 비교 방법에서 얻은 네 값 중 최솟값이 가장 큰 프레임을 선택했다. 184번의 최소 차이는 7.4493 mm다.
- **부록 그림 S1 (116번)** — CGR 행에서 `max_pad_q05_mm`가 가장 작은 프레임을 선택했다(0.2458 mm).

세 방법은 같은 손 관절 궤적과 공통 Panda 베이스, 카메라, 역기구학을 사용했다. Masquerade와 Ego2Robot은 각 공개 변환기를 15 Hz에 적용했고 CGR은 물체 형상, 주석된 물체 자세와 기하학적 접촉 후보를 추가로 사용해 30 Hz에서 처리했다. 거리와 가시성은 저장된 로봇 자세와 레몬 형상에 대한 지표다. [원본 데이터 카드](https://huggingface.co/datasets/HRDexDB/HRDexDB) · [도판과 출처](../figures/README.md)
